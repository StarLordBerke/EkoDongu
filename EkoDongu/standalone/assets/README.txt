Bu klasör, oyunun harici ses dosyaları için ayrılmıştır.
Aşağıdaki dosya isimleriyle kendi MP3 ve WAV ses dosyalarınızı ekleyebilirsiniz:

1. bgm.mp3      -> Arka plan döngü müziği (Background Music - Loop)
2. success.wav  -> Doğru kutu başarı zili (Ding efekti)
3. error.wav    -> Yanlış kutu veya yere düşme hatası (Buzzer efekti)
4. gameover.wav -> Oyun bitti melodisi (Game Over efekti)

Not: Dosyalar bu klasörde bulunmadığında oyun otomatik olarak Web Audio API sentezleyicisine geçiş yapar ve kesintisiz ses üretir.
